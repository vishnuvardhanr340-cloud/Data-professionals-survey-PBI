# Data Dictionary

File: `data/data_professionals_survey_cleaned.csv` (473 rows, 21 columns)

| Column | Description |
|---|---|
| Unique ID | Anonymous response identifier |
| Switched Career | Whether the respondent switched careers into data (Yes / No) |
| Salary Band Min (k USD) | Lower bound of the reported yearly salary band, in thousands of USD |
| Salary Band Max (k USD) | Upper bound of the salary band, in thousands (225 for the open-ended 225k+ band) |
| Salary Midpoint (USD) | Midpoint of the band in USD, used to calculate averages |
| Happiness - Salary | Satisfaction with salary, rated 0-10 |
| Happiness - Work/Life Balance | Satisfaction with work/life balance, 0-10 |
| Happiness - Coworkers | Satisfaction with coworkers, 0-10 |
| Happiness - Management | Satisfaction with management, 0-10 |
| Happiness - Upward Mobility | Satisfaction with chances to advance, 0-10 |
| Happiness - Learning New Things | Satisfaction with opportunities to learn, 0-10 |
| Difficulty Level | How difficult it was to break into data (Very Easy to Very Difficult) |
| Gender | Male or Female (after cleaning) |
| Age | Age in years |
| Age Group | Age band: 18-24, 25-34, 35-44, 45-54, 55+ |
| Education | High School, Associates, Bachelors, Masters, PhD |
| Programming Language | Favourite programming language |
| Top Job Priority | What matters most when looking for a new job |
| Industry | Industry the respondent works in (free text, not fully standardised) |
| Role | Grouped job role: Data Analyst, Data Engineer, Data Scientist, Student/Looking/None, Other |
| Country | Country of residence |
